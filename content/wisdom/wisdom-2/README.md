# Wisdom 2

This directory is a cleaned-up version of the original wisdom vault. It does not replace the source notes. It consolidates duplicate advice into canonical concepts and keeps source references so each merged idea can be traced back.

## Cleanup Rules

- One canonical note per repeated idea.
- Source notes are listed at the top of each canonical note.
- Exact duplicates were merged aggressively.
- Related-but-distinct ideas were kept as separate sections inside broader hub notes.
- Original files were left untouched.

## Canonical Notes

### Personal Growth

- [[concepts/Action Over Confidence]] - You do not need belief before action; action creates evidence.
- [[concepts/Action Over Preparation]] - Stop waiting for motivation, emotional readiness, or perfect strategy.
- [[concepts/Self-Trust Through Promises]] - Confidence is built by keeping commitments to yourself.
- [[concepts/Self-Worth Beyond Validation]] - Do not outsource self-worth to approval, achievement, or comparison.
- [[concepts/Presence Time and Busyness]] - Do not trade the present for future permission to live.
- [[concepts/Struggle Growth and Mental Toughness]] - Hardship can build capacity when it changes behavior constructively.
- [[concepts/Toxic Compassion and Truth]] - Appearing kind is not the same as doing good.
- [[concepts/False Social Consensus]] - Groups often misread what others actually believe or want.
- [[concepts/Late Stage Success Advice]] - Do not copy strategies people use after they have already won.
