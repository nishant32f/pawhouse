# Obsidian Value Map

This vault's publishable content lives under `public/`. Anything outside `public/` is private/runtime state and is not synced to the Quartz website.

The public content root currently has three operating areas:

- [[digests/AI X Digest Hub|digests]] — imported historical AI/X digests plus the daily generated digest stream.
- [[bookmarks/inbox|bookmarks/inbox]] — raw link capture inbox. Sort later.
- [[wisdom/Index|wisdom]] — ported digital-garden notes organized from the old TOC structure.

## Automation

Daily digests are generated by Hermes from `bird` CLI JSON and summarized into `public/digests/`.

The vault knowledge graph is maintained with [[Graphify Vault Dashboard|Graphify]]. Graphify outputs stay outside the hosted tree under `.graphify/`, including `graph.html`, `graph.json`, `GRAPH_REPORT.md`, and an Obsidian canvas export.
