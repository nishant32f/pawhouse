## Perplexity open-sources SPACE for isolated agent code execution
<!-- story-id: perplexity-space -->

Perplexity announced SPACE on October 15, releasing the sandbox platform it says runs every task in Perplexity Computer. The Apache 2.0 project gives each agent task its own Firecracker microVM.

The company says credentials and outbound traffic are controlled outside the VM. The documentation separates lifecycle operations from command results. An accepted create request does not mean a sandbox is ready. A completed command does not delete the sandbox.

The local guide requires an apt-based Linux x86_64 host with KVM, privileged Docker, loop devices and btrfs support. These instructions do not run directly on macOS. The guide deploys through Kind and Kubernetes. The architecture also documents a direct worker adapter. The local setup uses development passwords and signing keys. Keep it private and do not use production credentials.

Sources: [Perplexity's announcement](https://x.com/perplexity_ai/status/2110778478312481167), [SPACE repository](https://github.com/perplexityai/SPACE), [installation guide](https://raw.githubusercontent.com/perplexityai/SPACE/main/docs/installation.md), [architecture](https://raw.githubusercontent.com/perplexityai/SPACE/main/docs/architecture.md). First-party release and documentation.

## OpenAI rolls out GPT-Live-1.1 voices, including Hindi
<!-- story-id: openai-live-voices -->

OpenAI announced GPT-Live-1.1 on October 15 for Voice in ChatGPT, Codex and dots. It says the update brings new voices and better accents. The rollout covers all users; API access is coming later.

The announcement lists French, German, Hindi, Mexican Spanish, Korean and Japanese. It also promises less "checking..." during voice interactions, but gives no latency figures or language-by-language quality results.

If you build for Indian users, try the new Hindi voices in the consumer apps. Developers still need to wait for the API release before integrating GPT-Live-1.1. The announcement gives no API release date.

Source: [OpenAI's GPT-Live-1.1 announcement](https://x.com/OpenAI/status/2110797830361436604). First-party rollout and quality claims.

### Anthropic gives METR evaluators employee-like access
<!-- story-id: anthropic-metr-access -->

Anthropic said on October 15 that it has given a METR team employee-like access to assess its safety practices. It is also discussing evaluation arrangements with other organizations. This is an access announcement, not completed findings or a safety certification.

Source: [Anthropic's evaluator-access announcement](https://x.com/AnthropicAI/status/2110784662071398807). First-party statement.
